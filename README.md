## Getting Started
The following libraries are required.

`sdl3, sdl3_image, sdl3_ttf, sdl3_mixer`

## Note
To Build : `path_to_your_cmake_binary --build path_to_your_working_dir -j `\
To Run : `./build/name_of_your_executable`
